# UCE-eDNA
Pipeline to simulate UCE data and test methods for taxon identification and abundance estimates in eDNA samples. 


1) Reads are simulated using the capsim programe outlined in read-simuation code file
2) UCE reference contigs are used in the downstream analysis of these reads and can be generated using the program phyluce outlined in the generate-UCE-reference-contigs code file
3) Per-UCE-assembly is the current pipeline being tested on a simuated bony fish sample
